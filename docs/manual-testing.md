# Сценарії ручного тестування

Проходити зверху вниз: сценарії подекуди спираються на дані, створені раніше.
Перед початком — чиста тека даних, інакше очікувані результати не зійдуться.

**Підготовка.** У конфігурації запуску виставити `PA_DATA_DIR=/tmp/pa-test`,
перед прогоном видалити цю теку (`rm -rf /tmp/pa-test`) і запустити бот.

Позначки: **О** — очікуваний результат. Значення з пробілами вводяться **в
лапках** — це частина перевірки.

## С9. Файли (лише попередній перегляд)

**Підготовка.** Створити тестову теку — у вкладці Terminal PyCharm:

```bash
mkdir -p /tmp/pa-files/тека && cd /tmp/pa-files
printf 'однаково' > 'Мій звіт (1).PDF'; printf 'однаково' > kopiia.pdf
printf 'однаково' > 'тека/дубль.pdf'; printf 'фото' > 'Ґудзик.JPEG'
printf 'відео' > 'Відео з відпустки.MP4'; printf 'архів' > 'архів.tar.gz'
printf 'x' > no_extension; printf 'y' > already_normal.txt; printf 'z' > .DS_Store
```

| # | Крок | О |
|---|---|---|
| 9.1 | `sort files /tmp/pa-files` | План по категоріях images/videos/documents/archives/audio/others |
| 9.2 | Той самий вивід | `Ґудзик.JPEG → Gudzyk.jpeg`, `архів.tar.gz → arkhiv.tar.gz` (розширення ціле) |
| 9.3 | Той самий вивід | Рядок «(приховані пропущено: 1)» — `.DS_Store` не сортується |
| 9.4 | Той самий вивід | Останній рядок: «Це попередній перегляд — на диску нічого не змінено» |
| 9.5 | **Перевірити теку в Finder / `ls`** | **Нічого не змінилося** — жодного переміщення чи перейменування |
